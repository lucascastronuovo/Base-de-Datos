# Base de Datos - SQL  

Este repositorio contiene los ejercicios de **SQL** que desarrollé durante la materia **Base de Datos**. Los scripts están enfocados en el uso de SQL para resolver problemas relacionados con la manipulación y consulta de datos en bases de datos.  

## 📂 Contenidos abordados  
Los ejercicios en este repositorio incluyen los siguientes temas:  
- **Consultas básicas**: Selección de datos, filtros con WHERE, y ordenamiento con ORDER BY.  
- **Joins**: Combinación de datos de varias tablas usando INNER JOIN, LEFT JOIN, RIGHT JOIN, etc.  
- **Subconsultas**: Uso de subconsultas en SELECT, WHERE y FROM.  
- **Operaciones de manipulación de datos**: Inserción (INSERT), actualización (UPDATE) y eliminación (DELETE).  

## ⚠️ Aviso importante  
Este repositorio refleja el proceso de aprendizaje en SQL, por lo que algunos ejercicios pueden no estar completamente optimizados o podrían contener errores.  

## 🛠 Requisitos  
Para ejecutar los scripts de SQL, necesitas:  
- Un sistema de gestión de bases de datos (DBMS) como **MySQL**, **PostgreSQL**, **SQL Server**, o similar.  
- Un cliente de base de datos como **DBeaver**, **MySQL Workbench**, o la línea de comandos.
