Dado el siguiente esquema relacional:



CLIENTE (Nrocli, Nyape, Domicilio, Localidad, Saldocli)

FACTURA (Nrofactura, Cliente, Fecha, Total)

DETALLE (Nrofactura, Renglón, Artículo, Cantidad, Preciouni)

ARTICULO (Nroartic, Descripción, Rubro, Stock, Pto_reposicion, precio)

RUBRO (Cod_rubro, Descripcion) 

 

Resolver en SQL: 

Listar todos los datos de los clientes que NUNCA compraron durante este año. Ordenar el resultado alfabéticamente por nombre y apellido.

SELECT DISTINCT C.*
FROM CLIENTE AS C
WHERE C.NROCLI NOT IN (SELECT DISTINCT F.CLIENTE
			FROM CLIENTE AS C inner join FACTURA as	F on (C.NROCLI = F.CLIENTE)
				WHERE  year(F.FECHA) = 2021)
ORDER BY C.NYAPE ASC;

Listar todos los datos de los clientes que nunca compraron el artículo con código 4030.

SELECT DISTINCT C.*
FROM CLIENTE AS C
WHERE NROCLI NOT IN (Select NROCLI
						FROM CLIENTE AS C inner join FACTURA as F on (C.NROCLI = F.CLIENTE) inner join DETALLE as D on (F.NROFACTURA = D.NROFACTURA) inner join ARTICULO as A on (D.ARTICULO = A.NROARTIC)
						Where NROARTIC = 4030);


Listar los datos de las facturas de este año en que se vendieron artículos del rubro clavos (descripción).

SELECT DISTINCT F.*, R.DESCRIPCION AS 'RUBRO'
FROM FACTURA AS F inner join DETALLE AS D ON (F.NROFACTURA = D.NROFACTURA) inner join ARTICULO AS A ON (D.ARTICULO = A.NROARTIC) inner join RUBRO AS R ON (A.RUBRO = R.COD_RUBRO)
WHERE R.DESCRIPCION like 'Clavos';

Listar los datos de las facturas de este año en que NO se vendieron artículos del rubro herramientas eléctricas (descripción).

SELECT DISTINCT F.*
FROM FACTURA AS F
WHERE F.NROFACTURA NOT IN (Select DISTINCT F.NROFACTURA
							FROM FACTURA AS F inner join DETALLE AS D ON (F.NROFACTURA = D.NROFACTURA) inner join ARTICULO AS A ON (D.ARTICULO = A.NROARTIC) inner join RUBRO AS R ON (A.RUBRO = R.COD_RUBRO)
							WHERE R.DESCRIPCION LIKE '_erramienta _l_ctrica');
